Proyecto: Recursos de programación - INFORMATICA_IPDDVM
================

Descripción
-----------
Repositorio con los recursos estáticos (página web, imágenes y videos) relacionados con las prácticas y materiales del curso/proyecto "INFORMATICA_IPDDVM".

Estructura
----------
- `index.html`: página principal del sitio.
- `assets/`: recursos estáticos.
	- `docs/`: documentación y materiales en texto/PDF.
	- `img/`: imágenes organizadas por carpetas (`decimo`, `undecimo`, `duodecimo`, `logo`).
	- `videos/`: vídeos del curso.

Cómo usar
---------
1. Abrir `index.html` en un navegador web moderno (doble clic o arrastrar al navegador).
2. Si quieres servir el sitio localmente, desde la carpeta del proyecto puedes usar un servidor HTTP simple, por ejemplo con Python 3:

```
python -m http.server 8000
```

y luego abrir `http://localhost:8000`.

Contribuir
----------
- Añade nuevos recursos dentro de `assets/` respetando la estructura.
- Para cambios mayores, crea una rama, realiza commits claros y abre un pull request.
